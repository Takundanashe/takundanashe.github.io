Independent Vulnerability Research

Ongoing

Web application & API assessments · live production targets

  • Found exposed Spring Boot Actuator endpoints (/actuator/env, /actuator/heapdump) on live financial systems, leaking environment variables, credentials and heap memory.
  • Analysed downloaded JVM heap dumps with strings and Eclipse Memory Analyzer (MAT) to extract live session JWTs and password hashes, demonstrating session hijacking and offline cracking risk.
  • Discovered unprotected REST APIs exposing the PII of millions of users, including national IDs, phone numbers, addresses and dates of birth.
  • Reached sensitive transaction records and fund-transfer functions with no authentication or authorisation checks.
  • Mapped internal endpoints and data models through unprotected /v3/api-docs (OpenAPI) schemas.
  • Ran IIS 8.3 shortname enumeration with WAF bypass (tilde-encoding variants, HTTP method rotation, header injection) and built a Python scanner to automate it.
  • Performed passive DNS recon, certificate transparency analysis and Cloudflare origin IP discovery during black-box engagements.
  • Documented every finding in structured pentest reports with CVSS scores, reproduction evidence, risk ratings and remediation advice.
